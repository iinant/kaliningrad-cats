# 🐱 А когда я поеду в Калининград?

Мобильная игра по реальным объявлениям жилья в Калининграде: смотришь фотографии квартиры,
двигаешь котика-бегунок, называешь свою цену за ночь — и узнаёшь, насколько ты близок к правде.
За точность начисляются баллы-котики 🐾

## Правила игры

- 10 лотов за раунд, лоты выбираются случайно из реальных активных объявлений.
- Двигаешь бегунок с головой котика → жмёшь «Устраивает» → видишь реальную цену и разницу.
- Баллы-котики за отклонение от реальной цены:

| Отклонение | Баллы |
|------------|-------|
| ≤ 5 %      | 😻 5  |
| ≤ 10 %     | 😺 4  |
| ≤ 20 %     | 🐱 3  |
| ≤ 35 %     | 🙀 2  |
| ≤ 50 %     | 😿 1  |
| больше     | 🥲 0  |

- Максимум за раунд — 50 котиков.
- Итоговые вердикты:
  - 😿 **«Воздухан»** — ты систематически называл дешевле реальных цен (грустный котик без денег);
  - 😸 **«Хотите верьте, хотите нет»** — цены почти совпадали (весёлый котик);
  - 🤑 **«Очень необычно, зайка!»** — ты готов был переплатить (богатый котик с деньгами).

## Публикация на GitHub Pages (2 минуты)

1. Создай репозиторий на GitHub и залей код:
   ```bash
   git remote add origin https://github.com/<твой-логин>/kaliningrad-cats.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Source: `main` / root → Save**.
3. Через минуту игра доступна по адресу
   `https://<твой-логин>.github.io/kaliningrad-cats/`

Никакой сборки не требуется — это чистые `index.html` + `data.js`.

## Обновление данных

Данные берутся из [Google-таблицы](https://docs.google.com/spreadsheets/d/1BGdsrSql89RCn_bjsMP-Pk28enYxaziEk8Z3SBgpKAo/edit?usp=sharing):

```bash
curl -sL -o data_source.csv "https://docs.google.com/spreadsheets/d/1BGdsrSql89RCn_bjsMP-Pk28enYxaziEk8Z3SBgpKAo/export?format=csv"
python gen_data.py
```

Скрипт оставляет только лоты с ценой и минимум 4 фото и пишет их в `data.js`.
